# 平生 Liquid Glass UI 重构计划书

## 目标

把当前 Flutter App 的 UI 重构为接近 iOS 26 Liquid Glass 的视觉语言，同时保留平生现有的信息架构：财务、计划、饮食、锻炼、健康五个主模块，计划模块内继续保留今日、待办箱、周计划、复盘四个二级入口。

这次重构不追求“全屏都是透明玻璃”，而是做适合生活管理工具的版本：导航、顶部栏、弹层、关键摘要卡使用液态玻璃；任务正文、账单列表、表单输入区保持高可读实体底。

硬约束：重构只替换视觉材质，不改变原有 UI 结构、模块顺序、导航位置、卡片尺寸、内容密度和交互逻辑；除非是修复已知溢出，否则不主动调整业务页面布局。

## 设计假设

- 用户主要在手机上重复使用，信息读取效率比纯视觉炫技更重要。
- 之前项目多次出现过文字看不清、内容溢出、按钮误触问题，所以这次必须把可读性和触控范围放在视觉效果之前。
- Android 桌面小组件不适合做真实 Flutter 液态玻璃，只做同风格的轻量原生 XML 视觉，不纳入第一阶段。
- 预览图先以计划模块为主，因为它同时包含一级模块切换、二级导航、任务面板、联动数据和底部操作，最能代表项目结构复杂度。

## 视觉方向

### 玻璃层级

1. **背景层**  
   使用柔和但有内容感的渐变背景，加入蓝、青、紫、橙的流动光带，模拟参考图里的背景过滤效果。

2. **控制玻璃层**  
   顶部栏、主模块切换条、底部二级导航使用高透明度玻璃，包含背景模糊、白色描边、内高光和轻阴影。

3. **内容玻璃层**  
   今日执行、今日收支、7 天任务板使用中透明度玻璃，但内部文字区域保持足够白底遮罩，避免灰字压在复杂背景上。

4. **实体阅读层**  
   任务列表、财务记录、表单输入框保持 85% 以上不透明，重点解决可读性和溢出。

### 色彩

- 主色：蓝紫 `#5D72F6`，承接现有项目品牌。
- 辅助：青色 `#38BDF8`，用于液态边缘高光。
- 功能色：绿色收入/完成、红色支出、橙色饮食、紫色消耗。
- 背景：浅蓝到浅紫渐变，不使用大面积深色，避免生活工具变得压抑。

### 字体与密度

- 继续使用系统中文字体，避免引入字体包增加安装体积。
- 数据数字使用更大的字号，标题控制在 18-26。
- 所有卡片内容必须支持 390px 宽度，不允许横向滚动。

## 技术方案

### 第一阶段：设计系统与预览

- 新增独立预览页 `/liquid-glass-preview`，不影响正式业务入口。
- 建立 `GlassSurface` / `LiquidBackdrop` / `LiquidNavBar` 的设计样板。
- 输出静态 PNG 预览图，确认视觉方向。
- 验证：`flutter analyze` 和 `flutter test test\liquid_glass_preview_test.dart`。

### 第二阶段：共享组件落地

- 抽取正式共享组件到 `lib/shared`：
  - `LiquidGlassSurface`
  - `LiquidGlassHeader`
  - `LiquidGlassNav`
  - `LiquidMetricCard`
- 替换现有 `ModuleGlassHeader`、`ModuleLinkStrip`、`ModuleBottomNavSlot` 的视觉实现。
- 保持现有参数和回调接口，避免改动业务状态层。
- 验证：主模块切换测试、计划页导航测试。

### 第三阶段：计划模块重构

- 优先改计划页，因为它是最复杂的结构样板。
- 今日页：今日执行、联动指标、任务操作三块。
- 周计划：7 天任务板必须固定尺寸，`+5` 不再溢出。
- 待办任务：卡片点击不直接完成，只通过“完成 / 延后 / 归档”动作。
- 验证：`test\plan_widget_test.dart`。

### 第四阶段：财务、饮食、锻炼、健康迁移

- 财务：资产工作台、记录页、趋势图使用玻璃容器，但账单行保持实体白底。
- 饮食：餐次、热量、食物分类使用轻玻璃摘要。
- 锻炼：动作卡片保持清晰，开始训练浮层使用玻璃。
- 健康：状态趋势图和指标卡统一成液态玻璃摘要。
- 验证：对应模块 widget tests。

### 第五阶段：性能与无障碍

- 所有 `BackdropFilter` 必须被 `ClipRRect` 或 `ClipRect` 限定区域。
- 滚动列表中禁止每一行都使用强模糊玻璃。
- 同屏强玻璃层不超过 4 个。
- 支持深色模式时单独调整透明度，不直接反色。
- 验证：
  - 小屏 390x844 不溢出。
  - 字体放大后关键文字不重叠。
  - 所有按钮触控区域不小于 44px。

## 风险与取舍

- 真正接近参考图的动态折射需要 Shader 或第三方包，成本和性能风险较高。
- `liquid_glass_renderer` 和同类包可以作为第二轮增强，不放在首轮核心路径。
- 第一轮优先用 Flutter 原生能力模拟：`BackdropFilter`、渐变高光、描边、阴影、轻动画。
- 如果中低端 Android 出现掉帧，自动降级为半透明实体卡片。

## 成功标准

- 首屏看起来接近 iOS 26 Liquid Glass：透明、模糊、边缘高光、层次浮动明显。
- 仍能一眼看懂当前在计划模块，且能看到财务、计划、饮食、锻炼、健康五个主入口。
- 7 天任务板、今日支出、今日收入、饮食摄入、今日消耗不溢出。
- 计划二级导航仍在底部，不回到顶部。
- 自动化测试通过：`flutter analyze`、计划模块测试、预览页测试。
